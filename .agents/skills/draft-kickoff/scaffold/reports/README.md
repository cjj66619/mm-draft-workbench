# reports/ — 各阶段报告（人读 + 智能体读）

| 文件 | 由谁产出 | 内容 |
| --- | --- | --- |
| `ANALYSIS_MODELING_REPORT.md` | 建模阶段 | 问题拆解、数据理解、假设、符号表、模型公式、目标/约束、求解策略、决策与风险 |
| `DATA_REPORT.md` | 数据审计 | 附件清单、字段说明、质量问题、清洗步骤与影响、`data/clean/` 输出说明 |
| `RESULTS_REPORT.md` | 代码阶段 | **论文数值唯一来源**：每个结果表/数字 + 来源文件 + 生成脚本 + 参数/种子 |
| `ROBUSTNESS_REPORT.md` | 稳健性阶段 | 敏感性/扰动/基线对比证据 |
| `DRAWIO_REPORT.md` | 示意图阶段 | 每张示意图的用途、元素说明、已知缺陷 |
| `AUDIT_*.md` | 审计阶段 | 一致性 / 质量审计发现与处置 |
| `RUN_STATUS.md` | `run_all.py` 自动 | 最近一次复现各步骤结果（勿手改） |
| `PAPER_CHECK.md` | `tools/paper_check.py` 自动 | 论文章节自检：交叉引用 / 图路径 / 占位符 / 内部名泄露 + 图/表/公式编号表（勿手改） |
| `_logs/` | `run_all.py` 自动 | 每次运行的完整日志（已 .gitignore） |

写报告的原则：结论 + 证据（文件路径 / 数字 / 图），不写过程流水账；不确定的写"待确认"，不要编。
