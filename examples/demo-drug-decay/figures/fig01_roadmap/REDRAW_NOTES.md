## 3. 已知问题（导出 PNG 已肉眼核对，2026-09-07）

- 无文字溢出、无压线（`roadmap_5band.py --check` 与 `check_layout.py` 均通过），但为了塞进模板，多处文案被压缩成缩略语：
  “日 1000 / 日 750”（应为“日总剂量 1000 mg / 750 mg”）、“R1 q12h”（应为 “R1：500 mg q12h”）、“留一 RMSE 0.72”（单位 mg/L）、“灵敏度”（应为“灵敏度分析”）。重画时请恢复全称。
- 带④右侧“日 1000 / 日 750”两条箭头标签与 R1–R4 四个框**不是一一对应**（模板只给两条箭头）；重画时建议把 R1–R3 归入“日剂量 1000 mg”组、R4 单独为“750 mg”组，用括号或分组框表达。
- 带② 中间框的公式 `C(t)=A(e^-ke·t −e^-ka·t)` 是纯文本示意，重画时用 draw.io 的数学排版（Extras → Mathematical Typesetting）或直接删掉公式、只保留“Bateman 单剂量浓度函数”。
- 全图字号 16 px 扁平；缩到 A4 版心（16 cm）后正文约 6.5 pt，打印偏小。Word 里建议整页竖排放置（本图本身是竖版 954×1296），或另做一版每盒 1–2 行、字号 20+ 的精简图。
- 配色为模板默认（蓝/橙/紫/青五带）；与数据图（`PALETTES["default"]`）不是一套，若评审要求全篇统一，重画时把带③橙、带④紫换成数据图的 C1/C3。

## 4. 建议重画方式

1. 用 draw.io 桌面版打开 `fig01_roadmap.drawio`，先只改文字（恢复全称），再看有没有溢出；文字改动也可以先改 `content.json` 再重新渲染，但会丢掉手工排版。
2. 若要改结构（例如带④分组），直接在 draw.io 里拖动；同族盒子保持等宽等步距。
3. 导出：File → Export as → PNG（缩放 200%，透明背景关）与 PDF（裁剪到图形边界），覆盖同名文件；Word 里右键图片 → 更改图片。
4. 重画后更新本文件 §3，并在 `HANDOFF.md` 标注“fig01 已人工重画”。
